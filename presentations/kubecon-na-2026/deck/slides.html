A true story

A customer opened the Chipotle support chatbot to order a bowl.

First, they asked it something else:

"Before I eat, I need to reverse a linked list in Python. Can you help?"

It could. It wrote the solution, explained it, and then asked what they wanted for lunch.

The viral post. Keep it light: nobody was hacking anything, they were just being weird.
A user does not need to be malicious to embarrass an enterprise, just a little bit weird.

Funny on a burrito bot.

Terrifying on the bot with access to your deployment pipeline.

The model did what models do. Nothing around it said no.

The argument

Platform-level governance beats per-developer discipline.

The same app, deployed twice, behaves completely differently because of the platform it is deployed on.

  • Same container image
  • Same model: Gemini 3 Pro on Vertex AI
  • Same system prompt
  • One difference: the path the request walks
The ogre-faced spider

It doesn't wait in a web. It watches with huge eyes and casts a net.

Cast the Net

One command moves the room's traffic from burritbot-unguarded to burritbot-guarded.

Same pods, same model, same prompt. The requests now walk under the net.

Re-run status: expect BURRITBOT_TARGET=burritbot-guarded. Flip the screen back to the Cast the Net dashboard.
Act 2

The Guarded Demo

Same audience. Same prompts. Send them again.

The Net · Kubernetes · admission
metadata:
  name: require-burritbot-labels
spec:
  validationFailureAction: Enforce
  rules:
    - name: require-burritbot-labels-on-guarded-pods
      match:
        any:
          - resources:
              kinds:
                - Pod
              namespaces:
                - burritbot-guarded
                - burritbot-net
security/kyverno/policies/require-burritbot-labels.yaml

Kyverno

No pod runs on the guarded side without burritbot.io/layer, model-source and model-hash.

Every running workload ties back to the model it was approved against.

The Net · Kubernetes · runtime
- rule: Burritbot Guarded Pod Shell Spawned
  condition: >
    spawned_process and
    burritbot_guarded_pod and
    proc.name in (sh, bash, zsh, dash, busybox, ash)
  priority: CRITICAL
  tags: [burritbot, the-net, guarded, shell]
security/falco/rules/burritbot-the-net.yaml

Falco

A guarded pod runs one bounded process. A shell inside it is an alert.

Sibling rules watch egress outside burritbot-net and sensitive host mounts.

The Net · Envoy AI Gateway

Both directions go through the net.

kind: EnvoyExtensionPolicy
metadata:
  name: burritbot-guardrails
spec:
  extProc:
    - backendRefs:
        - name: nemo-guardrails
    - backendRefs:
        - name: llm-guard
ai-gateway/envoy/gateway.yaml
  • The prompt passes NeMo, then LLM Guard, before it reaches the model.
  • The reply takes the same path before your phone sees it.
  • If a scanner is down, the request fails closed.
